## Key Highlights for Hackathon Evaluators
- **Real Data:** Connects directly to Hyperliquid's official public API (`allMids`, `candleSnapshot`, `clearinghouseState`).
- **Real Local Machine Learning:** Local Python Scikit-Learn **Isolation Forest** anomaly detection without external cloud AI costs or hallucinating LLMs.
- **Read & Write Capability:** Complete simulated paper trading system with order preview, touch confirmation, and atomic SQLite state persistence.
- **Official SDK Integration:** Integrated with the official `@evenrealities/even_hub_sdk` and verified with `@evenrealities/evenhub-simulator`.
- **Packaging:** Pre-packaged and validated into `defi-guardian.ehpk` using official `evenhub pack`.
- **100% Free & Open:** Zero paid API keys, zero cloud costs, zero hardware required to test.
